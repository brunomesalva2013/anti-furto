# ESCUDO IA — Android nativo

Aplicativo experimental de proteção digital familiar assistida, com detecção local de indícios de fraude em prévias de notificações autorizadas.

- Proteção e acesso às notificações são opcionais.
- Não monitora conversas completas.
- Não envia alertas automáticos a familiares nesta versão.
- O projeto não guarda senhas, chaves Pix nem mensagens completas na nuvem.
- Não garante a detecção de golpes.

O GitHub Actions compila um APK Android de teste disponível em Artifacts após uma execução bem-sucedida.
